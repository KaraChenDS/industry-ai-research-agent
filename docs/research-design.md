# 研究设计与首轮验证

## 命题

通过通用知识搜集与专项研究确认实际AI使用场景，形成可复用的行业特征：使用流程、决策因素、行业/组织策略与用户心理；保留适用边界和反例。

“小型创业公司办公”是跨行业组织场景。首轮人为限定：中国大陆，5—50人，以知识工作为主的创业团队。这个范围是研究起点，尚未由用户确认。未来按业务类型、地区、规模、岗位及采用阶段分组比较。

## 研究问题

1. 最近一次具体任务是怎样从输入走到交付的？AI参与哪一步，人工补了什么？
2. 谁发起试用、谁使用、谁采购、谁验收？哪些因素导致持续使用或放弃？
3. 数据、预算、协作、责任和行业规则怎样影响工具选择与流程？
4. 当事人在具体事件中担心或期待什么？本人如何解释，而不是由研究者代替解释？
5. 同等交付质量下，准备、生成、检查、返工和维护的全部成本怎样变化？

## 最小研究轮次

时间预算约10.5小时，安排在7—10天内，访谈招募需按可接触性调整。无需购买报告；现金预算建议先设0—500元，实际由招募需要决定。

| 阶段 | 方法 | 完成标准 |
| --- | --- | --- |
| 公开知识 | 官方统计、行业软件帮助文档、从业者操作资料 | 记录出处、时间、样本和可迁移边界，提出问题而非提前定结论 |
| 分层访谈 | 4位一线、1位负责人、1位实施者；至少3个团队 | 覆盖持续使用、放弃和未使用，拿到最近真实事件 |
| 观察核对 | 获准使用的脱敏材料及操作演示 | 区分直接观察与口述，记录最终交付及人工补救 |
| 描述分析 | 小样本交叉对照、便利样本统计 | 保留相反案例，区分个人与企业单位，不推算市场规模 |
| 单任务验证 | 3—5份真实脱敏任务 | 先定义合格标准，再比较完整耗时；不能据此证明普遍稳定性 |

## 证据状态

- 公开背景：只能支持其原始地区、人群、年份、定义下的主张。
- 搜索摘要：日期、样本和全文未核，作为下一步检索线索。
- 访谈/问卷：当事人陈述，需要核对具体事件及自报数字。
- 直接观察：研究者记录的动作，仍需注意观察效应与单例边界。
- 研究者解释：推断，需要寻找反证。没有一手材料的场景全为待验证假设。

## 首轮Demo结果与尚未完成部分

已整理OECD中小企业研究、美国商会2026小企业报告、Anthropic编码交互研究及观察方法。它们并不是同一目标群体的可合并样本。

候选任务：知识检索与交接、对外内容交付、经营数据解读、内部轻量工具。候选来源是公开背景加研究者构造，并非已确认的高频需求。

目前没有真实访谈、没有问卷样本、没有目标团队的实测ROI；尚不能确认中国创业团队采用程度、采购动机和心理。下一步优先邀请不同使用阶段的从业者，并要求基于同一类任务对照。

## 继续或暂停

继续：不同团队出现相似任务与可核对材料，且有人愿意用下一次真实任务验证。

收窄：不同规模、业务类型或岗位差异过大；回到单一岗位与任务。

暂停：只能得到泛泛态度或厂商宣传、拿不到获准使用的材料；不要据此进入产品开发。
