# 小型创业公司办公场景 · AI应用现状研究

**研究状态：探索性研究；公开资料＋待验证假设，不是行业代表性调查。**

范围：中国大陆（待确认）；5—50人知识工作型创业团队。资料截止：2026-11-25。

## 现状解读

公开材料支持“值得研究中小团队的知识工作及人机协作”这一方向 [S1][S3]。美国小企业报告提供异地背景 [S2]，不能代替中国创业团队的现状数据。当前真实访谈与问卷样本均为0；以下场景是研究者提出的待验证假设，尚未确认使用频率、采购动机或心理。

来源编号可追溯不等于来源支持全部推断；请逐条人工核对。心理、策略和场景推断均应寻找反例。

## 场景特征与待核实问题

### 知识检索与任务交接

状态：待验证假设。证据：S1。

岗位：项目负责人 / 新成员；触发：接手项目，需要确认当前结论与责任人

流程：收集文档与消息 → AI提取候选结论 → 核对时间、出处与权限 → 向负责人确认后交接

决策因素：待问：来源可靠、更新及时、是否接入现有协作工具，哪个因素真正影响选择？

行业/组织策略：待问：由个人试用还是团队统一采购？文档权限与知识维护由谁负责？

用户心理（待核实）：假设：用户可能担心拿到过时结论；需以最近一次错误交接事件及本人表述核对。

反例/边界：资料少、负责人随时可问时，AI检索可能不如直接沟通。

下一步：请2个团队展示一次真实交接；比较原方法与AI方法的核对成本。

### 对外内容与方案交付

状态：待验证假设。证据：S1, S2。

岗位：运营 / 销售 / 创始人；触发：要向客户或公众提交材料

流程：确认对象与目标 → 整理获准使用的业务材料 → AI起草 → 人工核实事实和语气 → 审批与发布

决策因素：待问：交付质量、事实准确、修改次数、价格和协作便利性如何影响决定？

行业/组织策略：待问：是否有品牌规范、审批者与客户资料使用约定？

用户心理（待核实）：假设：用户可能同时希望提速并保持专业辨识度；不能据此给用户贴心理标签。

反例/边界：信息核实和修改耗时可能抵消起草速度。

下一步：拿3份脱敏交付物，事先约定质量标准，记录准备、生成、修改与审批总耗时。

### 经营数据解读与汇报

状态：待验证假设。证据：S1。

岗位：创始人 / 运营负责人；触发：需要解释一段时间的经营变化

流程：明确指标定义 → 导出获准使用的数据 → 清洗和计算 → AI提出解释候选 → 回查数字与业务事件 → 决定下一步动作

决策因素：待问：可复算、可追溯、数据接入和解释可信度是否影响使用？

行业/组织策略：待问：是否允许上传数据？谁维护指标口径、谁承担错误决策责任？

用户心理（待核实）：假设：负责人可能担心“看似合理但无法验证”的解释；需要真实决策事件。

反例/边界：口径混乱时，AI可能放大错误；简单固定报表可能更合适。

下一步：获取一份脱敏表及指标说明，对照人工计算，记录错误与检查成本。

### 内部轻量工具与原型

状态：待验证假设。证据：S3。

岗位：产品 / 技术 / 创始人；触发：有一个小任务想通过内部工具完成

流程：定义任务与完成标准 → AI辅助生成原型 → 用实际样例试跑 → 人工检查错误与数据处理 → 选择继续维护或放弃

决策因素：待问：试做速度之外，维护成本与实际可用性是否决定继续使用？

行业/组织策略：待问：谁能发布、谁负责维护、何时用现成产品替代自建？

用户心理（待核实）：假设：非技术成员可能期待自主完成，也担心无法定位错误；需区分岗位和经历。

反例/边界：厂商编码对话中的现象不能直接推广到非技术办公人员。

下一步：对照技术与非技术成员各一次真实尝试，记录成功、返工和放弃原因。

## 访谈提纲

- 0—5分钟：确认团队、岗位和近两周任务，选择最近一次具体任务。
- 5—15分钟：请展示获准使用的脱敏材料，逐步复盘输入、操作、AI交互、人工修改和最终交付。
- 15—20分钟：追问谁推荐、谁使用、谁采购、谁验收；为什么选择或放弃；比较现有替代办法。
- 20—25分钟：询问团队预算、协作和数据规则如何影响选择；用具体事件追问担忧与期待，不代替用户解释心理。
- 25—30分钟：核对总耗时、质量、失败例子；询问能否提供脱敏样例并约下一次任务复测。

## 问卷字段

- consent：是否同意将以下脱敏回答用于本次调研？
- respondent_id：匿名编号（例如团队A-01，不填写真实姓名）
- organization_id：团队匿名编号（同团队成员请填写相同编号）
- role：你的主要岗位或职责
- team_size：团队人数
- ai_status：过去两周，你在工作中使用AI的情况
- recent_task：最近一次具体工作任务是什么？当时需要交付什么？
- workflow：从收到任务到交付，依次做了什么？哪些步骤用AI，哪些自己做？
- decision：最近一次选择或放弃某个AI工具，主要考虑什么？谁决定购买？
- strategy：团队是否有工具、预算、数据使用、验收方面的约定？请举例；没有可填没有。
- psychology：最近一次使用或不用AI时，你最在意什么？发生了什么具体情况？
- baseline_min：同类任务原来总耗时（分钟，不清楚可留空）
- ai_total_min：使用AI后的全部耗时，含准备、检查、修改（分钟，不清楚可留空）
- quality_pass：AI辅助后的交付是否达到原有标准？
- failure：最近一次失败、返工或放弃AI的例子，以及最后如何完成任务

## 研究局限与下一轮

公开资料可能来自不同地区、年份、样本及AI定义，不能直接比较比例。厂商工具使用日志不等于企业采用率。

没有真实受访者时，不能确认目标群体使用习惯、购买动机、心理与业务收益。补充持续使用、放弃和未使用者的对照；用脱敏真实任务检验质量与全部成本。
