# Fieldnote · 行业 AI 应用现状调研 Agent

从公开知识走向真实工作场景：规划调研、搜集证据、解释现状、分析样本、生成问卷与访谈提纲，并交付带来源和边界的研究报告。

首个 Demo：**小型创业公司的办公场景**。初始范围为中国大陆、5—50人知识工作型创业团队，属于跨行业研究人群；可新建项目研究其他垂直行业。

> Research preview / v0.1。Demo收录真实公开来源，真实访谈和问卷样本为 **0**。场景流程、决策因素、组织策略和心理解释均为待验证假设。当前版本已验证本地研究流程；在线模型和搜索需用户配置服务密钥，未在本项目中完成真实付费服务验收。

### 完整本地工具：无第三方依赖

需要 Python 3.9+，不需要安装 npm、数据库服务或付费 SDK。

```bash
git clone https://github.com/KaraChenDS/industry-ai-research-agent.git
cd industry-ai-research-agent
python3 app.py
```

浏览器打开 **http://127.0.0.1:8765**。默认自动建立创业团队 Demo。数据保存在本机`data/research.sqlite3`，重启后仍保留。退出服务用`Ctrl+C`；端口冲突可用`python3 app.py --port 8766`。

### 可选：开启自主研究 Agent

```bash
cp .env.example .env
```

编辑`.env`中的`LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`，使用支持`/chat/completions`和function tool calls的服务，再重启。示例接口依据[DeepSeek官方工具调用文档](https://api-docs.deepseek.com/guides/tool_calls/)；模型名称应按你的服务账户实际可用模型填写，不保证所有兼容服务支持全部功能。

可选填写`TAVILY_API_KEY`以开启公开搜索，参考[Tavily Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)。没有搜索密钥时，Agent可使用手动录入的公开材料和一手资料，并标明不能联网。

界面运行前需要确认材料已脱敏，并同意把项目材料发送给所配置的模型服务。密钥只由后端读取，不进入网页、报告或Git提交。没有模型密钥时，界面明确提示，不会用预写内容冒充模型运行。

## 五项能力

| 能力 | 实现与输出 |
| --- | --- |
| 调研方法 / 任务拆分 | 研究简报、抽样方法、任务、时间上限、完成标准；在线模型可按行业调整 |
| 现状解读 | 结合证据和研究目标生成场景，区分背景、口述、观察、推断与反例 |
| 行业数据分析 | 记录外部统计的地区、年份、定义和分析单位；本地计算自采便利样本，拒绝将个人回答外推为企业渗透率 |
| 问卷 / 表单 / 访谈材料 | 生成JSON问卷结构与访谈提纲，导出独立HTML表单；受访者主动交回JSON文件 |
| 报告输出 | Markdown、可打印HTML/PDF、含私有材料的完整项目JSON；包含来源、局限和执行记录 |

每张场景卡覆盖：角色与触发、使用流程、决策因素、行业/组织策略、用户心理、反例、下一步、来源编号和证据状态。

## 为什么它包含 Agent，而不只是模板

模板提供无密钥的起点。在线模式中，**模型按证据缺口自主决定调用哪些工具、调用参数，以及何时结束**：

- `inspect_evidence`：查询本项目证据，包括脱敏访谈、观察与问卷回答。
- `analyze_dataset`：计算同意参与的自采样本及质量达标的配对耗时。
- `search_public_evidence`：可选联网搜集新线索，保留原始链接与“摘要未核”标签。

模型最多执行6轮、3次搜索；结果经过结构和来源编号校验，校验失败可在预算内修正。它**不自动采访真人、不自动发消息、不自动判断心理、不自动确认来源真正支持结论**。研究者需要核对语义支持关系及抽样边界。

## 一次完整操作

1. 查看创业团队Demo，或新建一个细分行业项目。
2. 核对研究范围，运行“调研方法与任务拆分”，形成待办；任务生成不等于任务完成。
3. 在证据页录入公开材料、脱敏访谈或直接观察。日期不明就填写“未核实”。
4. 运行“现状解读与场景特征”，检查流程、决策、策略和心理解释对应的材料。
5. 导出可填写HTML问卷。受访者在浏览器填写并下载自己的JSON回答，主动交给研究者；当前不提供云端自动回收。
6. 在样本分析页导入回答JSON、JSON数组或CSV；重复编号拒绝导入，不同意参与的内容不存储。
7. 用真实任务复测，补充失败/放弃案例，再运行综合报告并导出。

问卷字段及CSV模板：[examples/response-template.csv](examples/response-template.csv)。空模板不含虚构受访者。

## 数据和成本边界

- 自采问卷按匿名受访者统计，独立团队另计。便利样本只描述当前样本。
- 空白耗时保持缺失；只对质量达标且两项耗时完整的回答计算差值，负值保留。不把节省时间直接折成现金收入。
- 心理和策略需要具体事件及本人表述。即使有一手资料，也只标记为“待人工核对支持关系”。
- 公开来源来自不同地域、年份、定义与分析单位，不自动汇总为一个“行业采用率”。
- Demo使用无需密钥、无需调用模型。在线模式产生模型和可选搜索费用；有轮次/搜索/单轮输出上限，当前不提供货币额度硬限制。
- 默认仅绑定本机。此版本没有登录、租户隔离、云端回收或公网部署配置；如需在线多人协作，需另行设计。
- 不把真实资料写进Git。`data/`、`.env`、导出目录被忽略。完整项目导出仍含原始材料，请按研究授权使用。

## 验证与发布

```bash
python3 -m unittest discover -s tests -v
python3 scripts/build_demo.py
```

静态构建始终只读取人工整理的公开种子资料，不读取本机研究数据库，防止将私有访谈发布到静态Demo。`docs/`可用于GitHub Pages的分支发布模式（`main`，`/docs`）；只有静态展示、问卷下载和示例报告，真实Agent在本地后端运行。

如代码尚未推送，仓库所有者可先运行`gh auth login`，在提交代码后执行`sh scripts/publish.sh`，创建同名公开仓库并推送。脚本不上传未提交内容，检测到已跟踪的本地数据会停止。若已有`origin`远端，请核对后自行推送。

当前测试覆盖证据编号、确定性降级、问卷口径、缺失值、重复样本、负收益、导出转义、存储、模拟模型工具调用及轮次/搜索限制。**模拟服务测试不等于真实模型端到端验收。**
